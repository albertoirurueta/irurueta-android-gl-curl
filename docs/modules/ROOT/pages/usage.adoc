== Touch handling and rendering model

The view handles touch events itself: dragging from the right page curls it towards the left (next page), and dragging
from the left page curls it back (previous page). When the finger is raised, the flip is completed or reverted with a
short animation. A tap is reported to the xref:navigation.adoc#listeners[`PageClickListener`].

The view renders only on demand (`RENDER_MODE_WHEN_DIRTY`): setters such as `pageProvider`, `setCurrentIndex` or
`setBackgroundColor` request a new frame, and frames are rendered continuously only while a page is moving.
