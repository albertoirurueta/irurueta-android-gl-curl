== Requirements

* Android `minSdk` 26 (Android 8.0) or later.
* A device or emulator supporting OpenGL ES.
* The library is compiled against SDK 36 with Java/Kotlin JVM target 17.

The library exposes https://github.com/albertoirurueta/irurueta-android-glutils[irurueta-android-glutils] as an `api`
dependency, so `GLTextureView` and its lifecycle methods (`onResume`, `onPause`, `requestRender`...) are available to
your code without declaring it.

== Gradle (Kotlin DSL)

Make sure `mavenCentral()` is among your repositories (in `settings.gradle.kts`):

[source,kotlin]
----
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}
----

Then add the dependency to your module's `build.gradle.kts`:

[source,kotlin]
----
dependencies {
    implementation("com.irurueta:irurueta-android-gl-curl:1.1.6")
}
----

== Snapshots

Development versions built from the `develop` branch are published as `-SNAPSHOT` versions to the Maven Central
snapshots repository. To use them, add the repository:

[source,kotlin]
----
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven(url = "https://central.sonatype.com/repository/maven-snapshots/")
    }
}
----
